# Agricultural Monitoring Drone: AI System Specification

## Overview
This repository contains the PEAS framework specification and task environment analysis for an **Autonomous Agricultural Monitoring Drone**. This project was developed as part of the "Introduction to Artificial Intelligence" course.

## Project Summary
The agent is designed for early-stage crop disease detection. It utilizes on-board AI inference to process multi-spectral imagery in real-time, enabling farm managers to pinpoint and treat infected zones efficiently.

## Key Features
* **PEAS Framework**: Detailed breakdown of Performance measures, Environment, Actuators, and Sensors.
* **Environment Classification**: Analysis of the task environment (partially observable, stochastic, dynamic, etc.).
* **Utility Function Design**: A custom utility function balancing detection recall, mission time, and false positive rates.
